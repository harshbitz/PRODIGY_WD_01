See How It Works

How the Navbar Works

01. Fixed Position

The navbar uses position: fixed so it stays pinned to the top on every page and every scroll depth.

02. Scroll-Aware Style

Past 80px of scroll, JavaScript adds a class that switches the background from transparent to solid.

03. Hover Feedback

Each link gets an animated underline that slides in from the left on hover, powered entirely by CSS.
