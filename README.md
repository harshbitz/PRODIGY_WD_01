# 🚀 Responsive Landing Page

A responsive landing page built for **Prodigy InfoTech's Web Development Internship — Task 01**.

## 🔗 Live Demo
https://harshbitz.github.io/PRODIGY_WD_01/

## 📋 Features
- Fixed navigation bar that switches from transparent to solid on scroll
- Smooth hover animations on nav links (animated underline)
- Fully responsive with a collapsible mobile menu
- Built with plain HTML, CSS, and JavaScript — no frameworks

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla)

## 📂 Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — scroll detection & mobile menu toggle

## 🎯 What I Learned
Handling scroll events efficiently, building smooth CSS transitions, and structuring a fixed navbar that works across all screen sizes.
